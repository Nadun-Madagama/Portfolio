Leo Club Official Website

Technologies: WordPress, PHP, Custom CSS

The official website for the Leo Club of University of Kelaniya (uokleos.org). This project involved designing and developing a comprehensive digital platform using WordPress to represent the club's values, projects, and impact.

As a key member of the 5-person development team, I focused on the frontend architecture, ensuring a premium user experience with responsive layouts and smooth interactive elements. The site serves as a central hub for recruitment, event promotion, and showcasing the club's humanitarian efforts.

Key Contributions:

  • WordPress CMS implementation and theme customization.
  • Custom CSS development for unique branding and layout adjustments.
  • Ensuring responsive design and cross-browser compatibility within the WordPress ecosystem.
  • Collaboration within a team to manage content and technical configurations.
